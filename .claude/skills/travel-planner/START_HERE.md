# Travel Planner 사용 안내

항공권·호텔 바우처·대략적인 일정을 주면 AI가 자료를 읽고 필요한 확인을 거쳐 HTML 여행 페이지나 PDF 여행북으로 만듭니다. Claude와 Codex에서 같은 생성기·데이터를 사용합니다.

## 설치

- **Claude:** 이 ZIP 그대로 Customize → Skills에서 업로드한 뒤 활성화하세요. 코드 실행과 파일 생성이 가능해야 합니다. 자세한 경로는 `references/environments/claude.md`에 있습니다.
- **Codex:** ZIP의 `travel-planner` 폴더 전체를 작업 폴더의 `.agents/skills/` 아래에 놓고 `$travel-planner`를 사용하세요. 자세한 안내는 `references/environments/codex.md`에 있습니다.

AI에게 이렇게 요청하면 됩니다.

> travel-planner 스킬로 첨부한 항공권과 호텔 바우처를 읽고 여행 계획을 만들어줘. 하루에 너무 많이 걷지 않고 쉬는 시간을 넣어줘. 결과는 HTML과 PDF 둘 다 원해. 먼저 전체 일정과 항공·숙소를 보여주고 뒤에 일별 설명을 자세히 넣어줘.

PDF만 필요하면 “PDF만”, HTML만 필요하면 “HTML만”이라고 말하세요. 형식을 말하지 않으면 스킬이 한 번 물어봅니다. JSON은 “나중에 다른 대화에서 수정할 데이터도 백업해줘”라고 요청할 때만 별도로 제공합니다.

수정할 때는 원본 데이터 또는 기존 대화에서 “둘째 날 오후를 줄여줘. 확정한 저녁 예약은 유지해”처럼 말하면 됩니다. 공유용은 “예약번호와 개인 정보를 제외한 동행자 공유본”이라고 요청하세요. 첨부 문서와 설명 속 개인 정보도 AI가 확인해야 합니다.

## 결과물과 실행 조건

- HTML은 일정·예약·지도·현장 안내·비용·준비물·상황별 대안을 포함합니다. 현지 시간대가 있으면 여행 중 오늘 일정을 선택하며, 밝은 화면과 어두운 화면을 전환할 수 있습니다. 핵심 내용과 사진은 파일 안에 들어가며, 지도 타일과 외부 링크는 인터넷이 필요합니다.
- PDF는 일정 개요와 예약 정보를 앞에 두고 상세 설명이 이어지는 여행북입니다. PC·태블릿·모바일에서 읽을 수 있는 크기이며 모바일 전용은 아닙니다.
- 사진 검색·수집·배치는 기본으로 수행합니다. HTML 메인과 PDF 표지에는 도시·지역 대표 사진, 숙소 영역에는 지점·주소가 일치하는 실제 호텔 사진을 넣습니다. 호텔이 입주한 건물 외관은 외관 사진임을 표시합니다. 사진이 필요 없으면 “사진 없이 만들어줘”라고 요청하세요.
- HTML 렌더링은 Python 3.10+, 사진 최적화는 Pillow, PDF는 ReportLab/Pillow가 필요합니다. 실행 환경 확인은 AI가 수행합니다. 필요한 라이브러리가 없는 제한 환경에서는 해당 단계가 완료되지 않을 수 있습니다.
- 자료 판독·여행 조사·사진 검색은 사용 중인 AI의 도구를 사용합니다. 사진을 끝내 확보하지 못하면 빠진 사진과 이유를 알리고 검토가 필요한 초안으로 전달합니다. 확인하지 못한 값은 “미확인”으로 남깁니다. 자료만 넣으면 모든 예약·운행이 자동 검증되는 서비스는 아닙니다.
- 공유 파일 생성과 공개 웹 배포는 별개입니다. 카카오톡으로 PDF를 보내는 것은 사용자가 할 수 있으며 스킬이 임의 전송하지 않습니다.

`examples/sample-trip.json`의 스위스 6일 여행은 가상 예약·비용이 포함된 디자인 예시입니다. 실제 여행에 복사하지 마세요. `examples/minimal-trip.json`은 사진 없이 시작하는 작은 예시입니다.
